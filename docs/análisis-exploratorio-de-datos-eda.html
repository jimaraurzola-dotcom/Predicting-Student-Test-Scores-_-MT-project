2.1 Análisis exploratorio de exam_score (Target)

trainset %>%
  summarise(
    n = length(exam_score),
    media = mean(exam_score),
    ds = sd(exam_score),
    mediana = median(exam_score),
    minimo = min(exam_score),
    maximo = max(exam_score),
    Q1 = quantile(exam_score, 0.25),
    Q3 = quantile(exam_score, 0.75),
    IQR = IQR(exam_score)
  )
##        n    media       ds mediana minimo maximo   Q1   Q3  IQR
## 1 630000 62.50667 18.91688    62.6 19.599    100 48.8 76.3 27.5

La variable exam_score se analizó a partir de 630.000 estudiantes, donde cada fila representa un estudiante. El puntaje promedio es de 62,51 puntos, con una desviación estándar de 18,92 puntos.

El 50% de los estudiantes obtiene un puntaje menor o igual a 62,60 puntos, prácticamente igual a la media, lo que indica una distribución simétrica. El IQR es de 27,5 puntos (entre Q1 = 48,8 y Q3 = 76,3). El puntaje mínimo es 19,60 y el máximo 100.

  • Histograma de densidad de la variable:
trainset %>%
  ggplot(aes(x = exam_score)) +
  geom_histogram(aes(y = after_stat(density)),
                 binwidth = 5,
                 fill = "#c5b0ff",
                 color = "white",
                 alpha = 0.6) +
  geom_density(color = "darkblue", linewidth = 1.2) +
  coord_cartesian(xlim = c(0, 100), expand = FALSE) +
  labs(title = "Distribución de la calificación del examen",
       x = "Calificación del examen",
       y = "Densidad") +
  theme_bw()

La mayor parte de los puntajes se concentra entre 50 y 75 puntos y la forma es aproximadamente simétrica. Al final se ve un aumento en 100 porque es el puntaje máximo posible: 15.458 estudiantes (2,45%) lo alcanzan.

  • Diagrama de cajas y bigotes:
trainset %>%
  ggplot(aes(x = "", y = exam_score)) +
  geom_boxplot(fill = "#c5b0ff", color = "darkblue",
               outlier.color = "#2f0be0") +
  stat_summary(fun = mean, geom = "point", shape = 20,
               size = 3, color = "black") +
  labs(title = "Diagrama de cajas y bigotes de la calificación del examen",
       x = "",
       y = "Calificación del examen") +
  theme_bw()

El boxplot confirma lo visto en el histograma: la mediana (62,6) está prácticamente centrada entre Q1 (48,8) y Q3 (76,3), la media (punto negro) coincide con ella y no hay valores atípicos.

resumen_numericas <- trainset %>%
  select(where(is.numeric), -exam_score, -id) %>%
  pivot_longer(
    cols = everything(),
    names_to = "variable",
    values_to = "valor"
  ) %>%
  group_by(variable) %>%
  summarise(
    n = sum(!is.na(valor)),
    media = round(mean(valor, na.rm = TRUE),3),
    ds = round(sd(valor, na.rm = TRUE),3),
    mediana = median(valor, na.rm = TRUE),
    minimo = min(valor, na.rm = TRUE),
    maximo = max(valor, na.rm = TRUE),
    Q1 = quantile(valor, 0.25, na.rm = TRUE),
    Q3 = quantile(valor, 0.75, na.rm = TRUE),
    IQR = IQR(valor, na.rm = TRUE),
    .groups = "drop"
  )

2.3 Análisis exploratorio bivariado

  • A continuación, analizaremos la relación entre la variable objetivo exam_score y las variables numéricas independientes.

age vs exam_score

trainset %>%
  ggplot(aes(x = age, y = exam_score)) +
  geom_point(alpha = 0.4, color = "#c5b0ff") +
  geom_smooth(method = "lm", formula = y ~ x, se = FALSE, color = "red") +
  labs(x = "Edad", y = "Calificación del examen") +
  theme_bw() +
  facet_grid(. ~ "Dispersión entre la edad y la calificación del examen")

La calificación se distribuye igual en todas las edades (17 a 24 años), con puntos en todo el rango de 20 a 100. La línea de tendencia es casi plana: no se ve una relación lineal entre la edad y la nota.

study_hours vs exam_score

trainset %>%

  labs(x = "Horas de estudio", y = "Calificación del examen") +

Hay una relación positiva clara: a más horas de estudio, mayor calificación. La nube de puntos sube junto con la línea de tendencia y es la relación más marcada de las cuatro.
