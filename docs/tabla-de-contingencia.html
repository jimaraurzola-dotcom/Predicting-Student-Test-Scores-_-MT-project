Predicting Student Test Scores

5 Tabla de contingencia

Hasta ahora hemos comparado exam_score (numérica) entre los grupos de cada variable categórica. Una forma complementaria de explorar relaciones es a través de tablas de contingencia, que permiten estudiar la asociación entre dos variables categóricas usando la prueba \(\chi^2\) de independencia.

Para conectar este análisis con la pregunta de investigación del proyecto, creamos una versión categórica de la variable respuesta: resultado, que clasifica a cada estudiante como aprobado (exam_score >= 60) o reprobado (exam_score < 60).

trainset <- trainset %>%
  mutate(resultado = ifelse(exam_score >= 60, "aprobado", "reprobado"))

trainset %>%
  count(resultado, name = "Frecuencia") %>%
  mutate(Porcentaje = round(Frecuencia / sum(Frecuencia) * 100, 2))
##   resultado Frecuencia Porcentaje
## 1  aprobado     347803      55.21
## 2 reprobado     282197      44.79

El \(55,21\%\) de los estudiantes aprueba (exam_score >= 60) y el \(44,79\%\) reprueba, una distribución razonablemente balanceada para el análisis.

Como cada estudiante es una única unidad experimental clasificada simultáneamente según dos atributos, el contraste que corresponde es el de independencia y no el de homogeneidad. La hipótesis nula es entonces:

\[ H_0: \text{los dos atributos en la población son independientes,} \]

es decir, \(p_{ij} = p_{i\cdot}\, p_{\cdot j}\) para todo \(i\) y todo \(j\), frente a la alternativa de que no lo son.

A continuación, evaluamos si resultado está asociado con las dos variables categóricas que mostraron la mayor separación entre grupos en la sección anterior: sleep_quality y study_method.

  • resultado vs sleep_quality

Construyamos la tabla de contingencia:

observados_sq <- table(trainset$resultado, trainset$sleep_quality)
observados_sq
##            
##             average   good   poor
##   aprobado   111912 140482  95409
##   reprobado   91324  72607 118266

Calculemos los totales por fila, por columna y el total general:

fila_totales_sq <- rowSums(observados_sq)
col_totales_sq <- colSums(observados_sq)
total_general_sq <- sum(observados_sq)

fila_totales_sq
##  aprobado reprobado 
##    347803    282197
col_totales_sq
## average    good    poor 
##  203236  213089  213675
total_general_sq
## [1] 630000

Ahora, hallemos las frecuencias esperadas bajo \(H_0\):

esperados_sq <- outer(fila_totales_sq, col_totales_sq,
                   FUN = function(f, c) f * c / total_general_sq)
esperados_sq
##             average      good      poor
## aprobado  112200.14 117639.67 117963.18
## reprobado  91035.86  95449.33  95711.82

Verifiquemos el supuesto de la prueba: todas las frecuencias esperadas deben ser mayores o iguales a 5.

min(esperados_sq)
## [1] 91035.86

La frecuencia esperada mínima es de 91.035,86, muy por encima de 5, por lo que se cumple el supuesto y la prueba \(\chi^2\) es válida.

Seguido, calculemos el estadístico \(\chi^2\):

chi_cuadrado_sq <- sum((observados_sq - esperados_sq)^2 / esperados_sq)
chi_cuadrado_sq
## [1] 19530.58

Determinemos los grados de libertad:

gl_sq <- (nrow(observados_sq) - 1) * (ncol(observados_sq) - 1)
gl_sq
## [1] 2

Ahora, el valor crítico y la decisión al \(5\%\):

alfa <- 0.05
valor_critico_sq <- qchisq(1 - alfa, gl_sq)
valor_critico_sq
## [1] 5.991465
# Comparación
rechaza_H0_sq <- chi_cuadrado_sq > valor_critico_sq
rechaza_H0_sq
## [1] TRUE

Si calculamos el p-valor:

valor_p_sq <- pchisq(chi_cuadrado_sq, gl_sq, lower.tail = FALSE)
valor_p_sq
## [1] 0

Si usamos la función chisq.test del paquete stats nos queda:

chisq.test(observados_sq)
## 
##  Pearson's Chi-squared test
## 
## data:  observados_sq
## X-squared = 19531, df = 2, p-value < 2.2e-16

Como \(\chi^2 = 19531 > \chi^2_{0.05} = 5.9915\), con una confianza del \(95\%\) se rechaza \(H_0\): la prueba \(\chi^2\) de independencia \((\chi^2_{(2)} = 19531,\ p-valor < 0.001)\) nos indica que resultado y sleep_quality no son independientes, es decir, existe asociación estadísticamente significativa entre la calidad del sueño y el hecho de aprobar o reprobar el examen.

Calculemos la \(V\) de Cramer para medir la fuerza de esa asociación:

k_sq <- min(nrow(observados_sq) - 1, ncol(observados_sq) - 1)
v_cramer_sq <- sqrt(chi_cuadrado_sq / (total_general_sq * k_sq))
v_cramer_sq
## [1] 0.1760708

La \(V\) de Cramer obtenida es de 0,1761, lo que indica una asociación débil entre ambas variables.

Ninguna de las dos alcanza por sí sola para predecir con fuerza si un estudiante va a aprobar o no.
