Predicting Student Test Scores

4 Tabla de contingencia

Para estudiar la asociación entre dos variables categóricas creamos resultado, que clasifica a cada estudiante como aprobado (exam_score >= 60) o reprobado.

trainset <- trainset %>%
  mutate(resultado = ifelse(exam_score >= 60, "aprobado", "reprobado"))

trainset %>%
  count(resultado, name = "Frecuencia") %>%
  mutate(Porcentaje = round(Frecuencia / sum(Frecuencia) * 100, 2))
##   resultado Frecuencia Porcentaje
## 1  aprobado     347803      55.21
## 2 reprobado     282197      44.79

El 55,21% aprueba y el 44,79% reprueba. Como cada estudiante se clasifica según dos atributos, el contraste que corresponde es el de independencia:

\[ H_0: \text{los dos atributos son independientes} \quad vs \quad H_1: \text{no lo son} \]

Evaluamos resultado frente a las dos categóricas con mayor diferencia entre grupos: sleep_quality y study_method.

  • resultado vs sleep_quality
observados <- table(trainset$resultado, trainset$sleep_quality)
observados
##            
##             average   good   poor
##   aprobado   111912 140482  95409
##   reprobado   91324  72607 118266

Hallemos los totales y los valores esperados:

fila_totales <- rowSums(observados)
col_totales <- colSums(observados)
n <- sum(observados)

esperados <- outer(fila_totales, col_totales) / n
esperados
##             average      good      poor
## aprobado  112200.14 117639.67 117963.18
## reprobado  91035.86  95449.33  95711.82

Todos los esperados son mayores que 5, así que la prueba es válida. Calculemos el estadístico, los grados de libertad, el valor crítico y el p-valor:

chi_cuadrado <- sum((observados - esperados)^2 / esperados)
df <- (nrow(observados) - 1) * (ncol(observados) - 1)

alfa <- 0.05
valor_critico <- qchisq(1 - alfa, df)
valor_p <- pchisq(chi_cuadrado, df, lower.tail = FALSE)

chi_cuadrado
## [1] 19530.58
df
## [1] 2
valor_critico
## [1] 5.991465
valor_p
## [1] 0

Con la función chisq.test nos queda:

chisq.test(observados)
## 
##  Pearson's Chi-squared test
## 
## data:  observados
## X-squared = 19531, df = 2, p-value < 2.2e-16

Como \(\chi^2 = 19531 > \chi^2_{0.05} = 5{,}99\), con una confianza del 95% se rechaza \(H_0\): resultado y sleep_quality no son independientes \((\chi^2_{(2)} = 19531,\ p-valor < 0.001)\).

k <- min(nrow(observados) - 1, ncol(observados) - 1)
v_cramer <- sqrt(chi_cuadrado / (n * k))
v_cramer
## [1] 0.1760708

La V de Cramer es 0,176, es decir, la asociación existe pero es débil.
