Predicting Student Test Scores

6 Correlación lineal

En el EDA ya habíamos observado, a través de diagramas de dispersión, que study_hours y class_attendance parecían tener una relación positiva con exam_score, mientras que age y sleep_hours no mostraban un patrón claro. En esta sección cuantificamos esas relaciones con el coeficiente de correlación.

El coeficiente de Pearson es una medida paramétrica y exige, entre otros supuestos, que ambas variables tengan un comportamiento normal. Como ya establecimos que exam_score no sigue una distribución normal, verificamos ahora la normalidad de las cuatro variables numéricas independientes para decidir entre la correlación de Pearson (paramétrica) y la de Spearman (no paramétrica). Al igual que antes, descartamos Shapiro-Wilk por el tamaño de la muestra (630.000) y usamos la prueba de Lilliefors.

trainset %>%
  select(age, study_hours, class_attendance, sleep_hours) %>%
  pivot_longer(
    cols = everything(),
    names_to = "variable",
    values_to = "valor"
  ) %>%
  group_by(variable) %>%
  summarise(n = length(valor),
            est_lt = lillie.test(valor)$statistic,
            p_lt = lillie.test(valor)$p.value)
## # A tibble: 4 × 4
##   variable              n est_lt  p_lt
##   <chr>             <int>  <dbl> <dbl>
## 1 age              630000 0.115      0
## 2 class_attendance 630000 0.0611     0
## 3 sleep_hours      630000 0.0738     0
## 4 study_hours      630000 0.0628     0

Con una confianza del \(95\%\), ninguna de las cuatro variables numéricas proviene de una distribución normal (age: \(D = 0.1152\); study_hours: \(D = 0.0628\); class_attendance: \(D = 0.0611\); sleep_hours: \(D = 0.0738\); en los cuatro casos \(p-valor < 0.001\)). Al no cumplirse el supuesto de normalidad, usamos el coeficiente de correlación de Spearman en lugar del de Pearson, consistente con el enfoque no paramétrico usado en todo el proyecto.

  • study_hours vs exam_score

Hallemos primero el coeficiente de Spearman paso a paso. Como la variable tiene empates, los rangos se asignan por promedios y el coeficiente se calcula como la correlación de Pearson aplicada a esos rangos:

# 1) Vectores, rangos y tamaño muestral
x <- trainset$study_hours
y <- trainset$exam_score
n <- length(x)

rx <- rank(x)
ry <- rank(y)

# 2) promedios de los rangos
rxbar <- sum(rx) / n
rybar <- sum(ry) / n

# 3) desviaciones
rxc <- rx - rxbar
ryc <- ry - rybar

Sxy <- sum(rxc * ryc)   # sumatoria de productos centrados
Sxx <- sum(rxc^2)       # sumatoria de cuadrados centrados de los rangos de x
Syy <- sum(ryc^2)       # sumatoria de cuadrados centrados de los rangos de y

# 4) Coeficiente de correlación de Spearman
rho <- Sxy / sqrt(Sxx * Syy)
rho
## [1] 0.7697575

Usando la función cor tenemos:

cor(x, y, method = "spearman")
## [1] 0.7697575

Ahora veamos si la correlación es significativa. El estadístico de prueba para \(H_0: \rho_S = 0\) es

\[ t_0 = \rho_S \sqrt{\frac{n-2}{1 - \rho_S^2}} \]

con \(n-2\) grados de libertad:

# 5) Estadístico t para H0: rho_S = 0
gl <- n - 2
t_0 <- rho * sqrt(gl / (1 - rho^2))
t_0
## [1] 957.1365
# 6) Valor crítico t_(alpha/2, gl) para alpha = 0.05 (bilateral)
alpha <- 0.05
t_tab <- qt(1 - alpha/2, df = gl)
t_tab
## [1] 1.959968
# decisión
if (abs(t_0) > t_tab) {
  decision <- "Rechazar H0: la correlación es significativa"
} else {
  decision <- "No rechazar H0: no hay evidencia suficiente de correlación"
}
decision
## [1] "Rechazar H0: la correlación es significativa"
# 7) p-valor (bilateral) desde la t de Student
p_valor <- 2 * pt(-abs(t_0), df = gl)
p_valor
## [1] 0

Usando la función cor.test nos queda:

cor.test(trainset$study_hours, trainset$exam_score, method = "spearman", exact = FALSE)
## 
##  Spearman's rank correlation rho
## 
## data:  trainset$study_hours and trainset$exam_score
## S = 9.5952e+15, p-value < 2.2e-16
## alternative hypothesis: true rho is not equal to 0
## sample estimates:
##       rho 
## 0.7697575

El coeficiente obtenido a mano, \(\rho_S = 0.7698\), coincide exactamente con el de cor() y con el de cor.test() \((S = 9.5952\times 10^{15},\ p-valor < 0.001)\). Según la tabla de interpretación del curso, un valor entre 0,75 y 1,00 corresponde a una correlación positiva muy fuerte. Con una confianza del \(95\%\) se rechaza la hipótesis nula de ausencia de correlación: a más horas de estudio, mayor es la nota. Este es, por lejos, el predictor numérico más fuerte del conjunto de datos.

Para las tres variables restantes aplicamos directamente cor.test.

  • class_attendance vs exam_score
cor.test(trainset$class_attendance, trainset$exam_score, method = "spearman", exact = FALSE)
## 
##  Spearman's rank correlation rho
## 
## data:  trainset$class_attendance and trainset$exam_score
## S = 2.7025e+16, p-value < 2.2e-16
## alternative hypothesis: true rho is not equal to 0
## sample estimates:
##      rho 
## 0.351515

Se obtiene un coeficiente \(\rho = 0.3515\) \((S = 2.7025\times 10^{16},\ p-valor < 0.001)\), que al estar en el rango de 0,25 a 0,50 corresponde a una correlación positiva débil. La asistencia a clases está relacionada con el desempeño académico, pero de forma bastante más modesta que las horas de estudio.

  • sleep_hours vs exam_score
cor.test(trainset$sleep_hours, trainset$exam_score, method = "spearman", exact = FALSE)
## 
##  Spearman's rank correlation rho
## 
## data:  trainset$sleep_hours and trainset$exam_score
## S = 3.5005e+16, p-value < 2.2e-16
## alternative hypothesis: true rho is not equal to 0
## sample estimates:
##       rho 
## 0.1600479

Se obtiene un coeficiente \(\rho = 0.1600\) \((S = 3.5005\times 10^{16},\ p-valor < 0.001)\). Al caer en el rango de \(-0,25\) a \(0,25\), la tabla lo clasifica como sin correlación o muy débil: aunque el contraste resulta estadísticamente significativo, dormir más o menos horas prácticamente no se traduce en diferencias en el puntaje del examen.

  • age vs exam_score
cor.test(trainset$age, trainset$exam_score, method = "spearman", exact = FALSE)
## 
##  Spearman's rank correlation rho
## 
## data:  trainset$age and trainset$exam_score
## S = 4.1376e+16, p-value = 1.303e-08
## alternative hypothesis: true rho is not equal to 0
## sample estimates:
##         rho 
## 0.007163204

Se obtiene un coeficiente \(\rho = 0.0072\) \((S = 4.1376\times 10^{16},\ p-valor = 1.303\times 10^{-8})\), es decir, sin correlación. A pesar de que el tamaño de muestra hace que hasta un coeficiente tan pequeño resulte significativo, su valor es prácticamente cero: la edad del estudiante no tiene ninguna relación relevante con su desempeño en el examen, confirmando lo que ya se veía en el diagrama de dispersión del EDA.

Este es un buen ejemplo de la advertencia que hace el curso sobre el coeficiente de correlación: una correlación débil puede ser estadísticamente significativa y una fuerte puede no serlo, dependiendo del tamaño de muestra, la variabilidad y el poder de la prueba. Con 630.000 observaciones, la significancia estadística deja de ser informativa por sí sola y hay que apoyarse en la magnitud del coeficiente.

En conjunto, de las cuatro variables numéricas independientes, study_hours es por mucho la que mejor se relaciona con exam_score (\(\rho = 0,77\), correlación positiva muy fuerte), seguida bastante más atrás por class_attendance (\(\rho = 0,35\), correlación positiva débil). sleep_hours (\(\rho = 0,16\)) y age (\(\rho \approx 0\)) prácticamente no aportan nada. Y comparando con las secciones anteriores, ninguna variable categórica (ni siquiera sleep_quality o study_method) se acerca a la fuerza de esta relación. Todo apunta a que study_hours va a ser el predictor más importante cuando lleguemos a la regresión lineal simple.
